Limitations
-----------
These tests cover blocking package-private store APIs and real SQLite recovery.
They do not expose producer-1 declaration, admit or execute work, allocate child
scopes, settle closure, publish/read results, retire sessions, or exercise the
wire dispatcher. snapshot() is one immediate observation; optional WATCH wait
scheduling and deadlines remain outside this API. No Java durable profile was
advertised over QUIC, and no Rust parity or full V2 conformance is claimed.
No Rust source changed and no Rust workspace suite or native transport
bootstrap was rerun; unchanged retained binaries exercised the existing
runtime examples. Rust receipt/membership reconciliation and the both-language
failure/resource gates remain open.
