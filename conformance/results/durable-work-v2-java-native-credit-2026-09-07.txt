Behavior and regression oracles
-------------------------------
- Explicit initial connection replenishment window, independent of initial
  advertised MAX_DATA, clamped to the configured maximum at connection creation.
  Setter order does not matter; unset preserves upstream default behavior.
  Autotuning/stream lower bounds still apply. Zero is not a general disable flag.
- Saturating native retained-span counter: sum of written stream offsets beyond
  each contiguous ACK frontier. ACKed tails behind a hole stay charged. Packet
  emission/retransmission and completed Java writes do not release it. Local
  reset and peer STOP_SENDING clear their send-buffer charge. FIN adds no bytes.
- Connection-wide send cap and protected slice, with trusted per-stream control
  classification. Both direct and composite native writes, plus automatic queue
  retries, use the same current aggregate limit. JNI saturation fails closed.
- Real loopback tests withhold ACKs, fill ordinary admission, deliver reserved
  bytes and exercise a zero-reservation negative control. Classification applies
  to queued and future writes; off-event-loop changes after registration refuse.
- FIN must follow all queued payload. ByteBuf plus shutdownOutput and data-bearing
  FIN-frame tests require exact composite bytes, withheld FIN during saturation,
  and complete bytes plus FIN after acknowledgments restore capacity.
- Local output reset fails pending/future writes with ChannelOutputShutdownException,
  remains nonwritable across an event-loop barrier, and releases only native
  buffers it owns so another stream can progress. Peer reset ID/code are exact.

The counter is not exact memory: partial backing-buffer prefixes, metadata,
TLS, datagrams and Java queues are outside it. Native copying can retain one
ACKed prefix up to 4095 bytes per send stream. Custom zero-copy backing storage
can retain more. Scanning live streams also requires a stream-count bound.
No congestion-window reservation, peer-credit guarantee or delivery deadline
is supplied by this native admission API.
