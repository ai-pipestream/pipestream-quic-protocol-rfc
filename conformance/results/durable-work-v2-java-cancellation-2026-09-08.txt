Java V2 cancellation, skip and bounded settlement, 2026-09-08

Scope
  Work cancellation/skip and scope cancellation now accept immutable receipts
  in the same owner-authorized transaction as their exclusion fences. A prior
  terminal outcome is unchanged. The first own fence fixes the promised outcome;
  identical operations replay under current authorization without new time.
  Unadmitted declarations can settle at attempt zero without invented input.

  Ancestor checks immediately exclude new declaration, admission, retry and
  publication. An unresolved branch remains CANCELLING until actual child
  closure. Local administrative revocation denies the retained owner while
  owner-independent maintenance settles declared and admitted obligations.
  Previously terminal descendants and earlier own skip outcomes are preserved.

  Descending keyset sweeps inspect at most limit direct work and limit direct
  membership IDs per call, with one scope digest in progress. No partial seal is
  advertised or retained. Restart recomputes from frozen rows. Closure is a
  separate terminal-status fold; monotonic cancellation/revocation flags restart
  partial folds without changing pinned membership. Ancestor validation and
  reservation-header scans add work beyond these direct-record counters.

  Private schema 7 retains typed own fences, pending jobs and cancellation
  journal kinds. Scope-cancellation indexes are checked against typed requests.
  Recovery requires direct/inherited fence provenance and valid terminal
  intervals and child-closure ordering. Earlier private schemas are refused
  without conversion. Wire grammar, commitments and normative cancellation
  semantics are unchanged; Appendix D records implementation progress.

  JOB_CREDITS is now eight: a conservative four-write lifecycle envelope plus
  four cleanup intent/completion writes. WORK retains four admitted credits and
  each own FENCE one. Input/output files and funding stay charged at cancellation;
  this does not implement cleanup or claim to undo external effects.

Reviewed test scope
  FenceStoreTest covers attempt-zero cancel/skip, terminal disposition one,
  pending mode-2 cancellation, same/conflicting later operations, old-publication
  refusal, deadline precedence, distinct skip policy, final access/application
  and clock rollback, replay without clock sampling, actual scope sealing and
  settlement, and operation collisions. Missing accepting receipts with adjusted
  operation counts and redirected cancellation indexes are refused on recovery.

  CancellationReconciliationTest uses a real admitted mode-1 branch with skipped,
  leased and unadmitted children. It checks immediate mutation refusals and exact
  final count partitions/seals, reopening during an incomplete seal and resuming
  with fresh limit-one cursors. Further cases cover closure interrupted by a
  monotonic scope fence, revoked-owner maintenance, cursor installation binding
  and invalid batch sizes. A mode-2 pending-to-terminal path retains at least
  four job cleanup credits. These are transaction/reopen tests, not newly added
  process-death or cross-language wire cancellation tests.

  Static review corrected scope-cancellation tests that expected immediate
  descendant settlement, and a pending-branch fixture that omitted the separate
  closure pass. No placeholder seal or terminal-before-closure exemption was
  added to production to satisfy those expectations.
