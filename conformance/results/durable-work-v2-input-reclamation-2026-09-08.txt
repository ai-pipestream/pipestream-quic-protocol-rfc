Implemented scope
  Private format 8 replaces the unused release discriminator with independent
  nullable input/output eligibility timestamps. Refunded charges require retained
  evidence; unsettled jobs cannot carry it. Recovery checks work/attempt/input,
  terminal time, trusted UTC watermark and actual child closure. Output eligibility
  additionally checks external retention and dependent parent settlement, although
  this checkpoint supplies no output-deletion operation.

  SessionStore.reclaimInput addresses one admitted job under exclusive paired-store
  ownership. It verifies live input before committing its first release timestamp,
  so missing live bytes cannot manufacture eligibility. A second writer transaction
  revalidates the retained evidence before synchronized physical removal and quota
  completion. Input eligibility survives both commit boundaries and logical refund.
  Current UTC is checked before destructive work; an unsafe final sample leaves
  the prior intent and conservative logical charge for a later safe invocation.

  Active input receivers retain exact-object identity through synchronized staging
  cleanup, including delayed duplicate FIN. Reader and receiver pins are separate
  from unborrowed receive credits and block physical removal. Same-process pending
  unlink/sync accounting retains exact physical charges until synchronization
  succeeds. Recovery reconstructs physical usage, then requires valid metadata
  evidence for a missing input. Metadata-only reference derivation still validates
  the exact input name after its bytes have been released. Output funding, terminal
  work views, manifests and closure commitments are unchanged by input reclamation.

Remaining boundaries
  This is one-target input reclamation, not a complete fair cleanup scheduler.
  Existing child-closure verification performs a session-wide streaming audit;
  its cost is not hidden by the target count or advertised as constant time.
  Output reclamation, bounded orphan reconciliation, fair sweeps and session
  retirement remain required. So do Java's durable endpoint/client, both-direction
  neutral failure/resource evidence, and the original external workload with an
  equivalent authenticated durable streaming-gRPC baseline. The full goal remains
  active. Rust code and wire grammar did not change in this checkpoint.
