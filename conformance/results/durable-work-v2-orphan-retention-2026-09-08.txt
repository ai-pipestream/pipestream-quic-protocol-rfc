Implemented scope
  Independent Java local maintenance: known-session, declared-work orphan
  reconciliation; bounded physical discovery; automatic terminal input/output
  cleanup; exact physical pins; service shutdown and retry ownership. No wire
  schema or private database format change. No Java durable endpoint claim.

  OrphanStore checks member/job/receipt identity in a paired writer snapshot.
  Missing admitted metadata is corruption, not deletion authority. Input body
  hashes and exact storage names are checked before unreferenced deletion.
  Funding with execution outputs refuses. Unlink and directory synchronization
  precede refunds. Same-process uncertain charges survive service replacement
  and block same-name installation until retry. Restart reconstructs usage
  behind the existing startup directory-synchronization barriers.

  RetentionService visits at most 1..64 configured job and physical candidates
  per call. Jobs use finite keyset sweeps; physical discovery uses one charged
  directory handle and at most the immutable file-policy entry ceiling per
  weakly consistent pass. Failed orphan retries can delay later orphans but do
  not stop job cleanup. Stop does not interrupt physical I/O or accepted work.

  Produced input FIN and admission, including reuse of installed input, share
  the payload-store monitor so cleanup cannot enter the unpinned handoff gap.
  Cached hints distinguish live admission, no admission, and checked completed
  release. A completed release requires physical absence and no uncertain
  charge; resurrected files remain corruption, never newly deletable orphans.

Scope limits
  Unknown or retiring sessions refuse orphan deletion. Durable session retirement
  remains unimplemented in Java. Directory discovery is not a snapshot or an
  arbitrary-mutation fairness proof. Existing child-closure audits retain their
  session-wide streaming cost. Page/handle bounds are not measured process RSS,
  device-space, actual I/O or hard latency bounds. Java durable transport/client,
  the independent two-direction failure/resource driver, and the complete external
  workload/equivalent authenticated durable streaming-gRPC comparison remain.
  No Rust production change or new full Rust suite run in this increment.
  This is local verification, not hosted CI, main merge, deployment, IETF
  submission, task-2 acceptance or completion of the full goal.
