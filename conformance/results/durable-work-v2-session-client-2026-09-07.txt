One development test incorrectly expected WAIT_TIMEOUT for a WORK watch. The
current contract returns the unchanged view on WORK wait expiry; only an
unfinished checkpoint wait returns WAIT_TIMEOUT. The assertion was corrected
after checking Section 12; implementation/spec were not weakened to satisfy it.

Structural ceilings: 64 facade owners, 1..=32 operations/internal replies per
facade (default 16). Cancelled waiters retain their slot through collector/reply
cleanup; returned output handles retain it until dropped. Journal operations
serialize off the control reader. The tests use a one-slot journal. These are
count/ownership assertions, not measured heap/RSS/disk/network/latency claims.
