V2 local Java result leases and Rust read commit time, 2026-09-08

Scope
  Java independently reads authenticated retained manifests and opens exact
  published work/attempt/index/digest objects. A historical worker identity
  locates bytes but grants neither execution nor result permission. Published
  work and job identity are checked together. Manifest retrieval does not
  consult UTC or assert that expired bytes remain available.

  Fresh reads pin the verified physical descriptor inside the writer transaction
  that checks current result permission and availability and remembers safe UTC.
  Final authorization, elapsed-lifetime and UTC checks follow file verification.
  Precommit failure closes the pin and rolls back the watermark. A JDBC-resource
  close failure after commit also closes the pin before propagating failure;
  the caller has not received that descriptor. The output path hashes once on
  the opened descriptor, not once to find it and again to open it.

  ResultService owns one registry for the exclusively paired input installation.
  Deployment global and per-owner counts span connections and include acquiring
  and pending reads. Every opened descriptor also consumes the existing shared
  input/output handle pool. One bounded chunk may remain outstanding per read.
  Actual accepted transport payload progress may consume that chunk partially;
  a disk read, check, stream start or empty progress does not renew idle time.

  Local elapsed deadlines include file acquisition and waiting for a response
  stream. Independent timer sweeps inspect a finite snapshot of at most 128
  entries. Busy I/O remains charged and foreground paths recheck after blocking
  work. Normal signed nanoTime values and wrap are supported by subtraction.
  Revocation/current permission remain gates on further scheduling; existing
  leases do not resample UTC or become unbounded after external output expiry.
  FIN or abort closes physical pins, not durable output-byte funding. Failed
  physical closes remain charged; shutdown cannot detach a live storage owner.

  Rust already supplied result delivery but sampled availability only before
  output verification. It now checks final safe UTC after the final ReadResult
  permission callback, refuses intra-operation regression or exact expiry, and
  retains that final sample rather than the earlier one.
