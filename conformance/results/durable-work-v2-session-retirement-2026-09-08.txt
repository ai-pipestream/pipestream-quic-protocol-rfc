Implementation scope
  Private metadata format 9 owns an immutable fixed-capacity retirement record.
  Eligibility binds creation identity, exact closed root, all retention cutoffs,
  safe UTC and required allocator history. A flag alone never authorizes a
  partial-state audit exemption. Missing mandatory root evidence is corruption.
  Intent commits before any metadata deletion; authorized owner requests expire
  during partial cleanup, with wrong-owner/revoked denials taking precedence.
  Bounded transactions delete jobs, non-declaration operations, entities,
  declaration operations, child scopes, then root/proof/session atomically.
  Authority generation and owner creation high-water marks survive completion.
  Paired storage installs current generation checks at input begin, funding and
  FIN; session receiver pins include uploads before their final name exists.
  RetentionService visits finite generation sweeps and one metadata unit per
  candidate, with independent counters and safe scanner shutdown.

Scope limits
  Record/bundle/page bounds do not measure whole-process RSS, actual device I/O,
  physical allocation or hard latency. Eligibility/recovery and fixed-record
  accounting retain streaming scan costs. The retirement proof uses protected
  ordinary allocation, not a newly proven full-store retirement capacity reserve.
  Java durable transport/client, the neutral two-direction failure/resource
  driver and external workload/equivalent authenticated durable streaming-gRPC
  comparison remain mandatory. No Java durable-profile advertisement was added.
  This is local implementation evidence, not hosted CI, main merge, deployment,
  IETF submission, task-2 acceptance or completion of the full goal.
