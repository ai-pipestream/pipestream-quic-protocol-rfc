Contract and implementation
  Java declares, preflights and admits producer-1 children through local APIs
  tied to the current mode-2 parent lease and exact allocated child scope.
  The owner, database/input installation, attempt, lease, deadline, application
  policy and ancestor fences are checked through commitment, including replay.
  Producer namespaces are separate in operation lookup, normative commitments,
  private checksums, foreign-key links and recovery audits. Caller input APIs
  remain producer-0 only. Shared admission code still funds actual immutable
  input, output allowance, work/job records and the original operation receipt.

  A final parent authorization check can outlive a shorter new child deadline.
  Java now validates both intervals at the same final UTC sample. Inspection
  found Rust local declaration/admission checked parent ownership near the start
  but not after final authorization. Rust now repeats that fence at commitment
  and after retained local receipt validation. New child admission checks the
  same final parent/child time and persists the final watermark. New empty-root
  closure also refuses clock regression or an already exhausted receipt interval.
  Existing external receipt observation remains available under unsafe time.

  Section 12.5 explicitly requires the final new-admission deadline check after
  storage and authorization. An expired new child is refused DEADLINE_EXCEEDED;
  its declaration is not erased. There is no new wire record, profile or local
  storage-format revision. This does not enable Java mode-2 callback scheduling
  or infer expansion completion from a seal.

Limits and remaining work
  Java local producer APIs do not yet provide expansion callbacks, phase-specific
  receiver credits, durable expansion completion or full retry/cancellation,
  result delivery, retention/retirement or durable transport/client integration.
  Existing guarded file geometry and bounded-record costs remain; the additional
  parent checks do not demonstrate constant-time transactions or whole-process
  resource limits. The neutral cross-language failure driver and the original
  external workload/equivalent authenticated durable streaming-gRPC comparison
  remain mandatory. Further final-time audits must cover the other worker and
  publication transitions; these admission/declaration tests do not prove them.
  The full goal remains active and incomplete.
