This is a real Java library foundation, not a V2 endpoint or full goal completion.
Independent Java authentication, request correlation, incremental object transfer,
durable execution, cancellation/retry/retention, client recovery and end-to-end
parent/child evidence validation remain required. The neutral Rust failure driver
and original external workload/equivalent authenticated durable streaming-gRPC
comparison remain mandatory. No profile is advertised by this library.

Implementation:
- Immutable typed control families and every Appendix F record/outcome. Arrays and
  lists are defensively owned. No generic object-tree/JSON conversion or Rust link.
- Schema-directed canonical CBOR and strict UTF-8. Length/cardinality checks precede
  body/list allocation. Integers use V2's nonnegative 63-bit range,
  not V1's uint64 model.
- Incremental control framing, unsigned-u32 bounds, bounded zero-buffer ignored
  bodies and fatal decoder poisoning; exact standalone object-header encoding.
  This does not yet implement timed incremental object streams or correlation.
- Profile intersection, required-set echo, dependency and minimum-limit checks.
- Originator-qualified typed operation hashes exclude only connection request IDs;
  target producer is not substituted for the operation originator.
- Streaming scope seals, typed manifest/status-leaf hashes and a 63-slot status
  frontier with V2 odd-last duplication. Scope identity, ascending IDs, exact
  counts, terminal-only leaves and child-root presence are validated. These hashes
  do not independently prove membership, authorization, execution or child closure.
- WAITING_CHILDREN without a child allocation now fails structural validation.
