repairs, not production-protocol changes. The Layer-0 positive fixture check uses
the raw sealed test peer for TLS/negotiation; actual public Layer-0 success remains
the full interoperability matrix's responsibility.

Remaining scope
---------------
Java V2 durable objects, admission/execution/fences, results, retention/retirement
and client recovery remain incomplete. The shared native data/control reservation
is not solved by this upgrade. The neutral Rust process/failure driver, complete
both-language outcomes/refusals/restart/resource evidence and original external
chunk/distribute/transform/reassemble workload with an equivalent authenticated
durable streaming-gRPC baseline remain mandatory. Core and existing V1 interop
tests cannot replace them. No goal completion, main merge, deployment or draft
submission is claimed.
